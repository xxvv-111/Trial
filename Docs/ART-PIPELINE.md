## 1. 结论摘要（TL;DR）

| 问题 | 结论 |
|---|---|
| 能否生成 3D 模型？ | ✅ **能**，但**当前 5 个 provider 全部未配置**（`configured: false`），需要你填 API Key |
| 能否生成 3D **动作/动画**？ | ⚠️ **AI 文生动作目前不可靠**。正确路线是：**新角色（Humanoid 绑定）复用现有动画**（重定向），或从 Mixamo 取免费人形动画 |
| 必须有 Blender 吗？ | ❌ **不必须**。本机也未安装。仅在做"批量重定向/减面/格式转换/合并材质"时才需要，且可用命令行驱动 |

**一句话**：模型可以 AI 生成或从市场下载；**动作必须走"重定向复用 + Mixamo 补充"**，这是唯一现实且高性价比的路。

## 3. 我（AI）当前可以调用的生成 / 导入能力

以下是本机 Unity 已装 MCP 插件暴露的能力，我**可以直接调用**，无需你手动操作（除了填 Key）：

| 能力 | 工具 / Provider | 产出 | 需要什么 | 现状 |
|---|---|---|---|---|
| **文/图生 3D 模型** | `generate_model` → **Tripo** | glb/fbx 静态网格（支持**自动绑定人形骨骼**、可选贴图） | Tripo API Key | ❌ 未配置 |
| **文/图生 3D 模型** | `generate_model` → **Meshy** | 同上 | Meshy API Key | ❌ 未配置 |
| **模型市场搜索+导入** | `import_model` → **Sketchfab** | 现成模型（**部分自带动画**、有明确授权信息） | Sketchfab Token | ❌ 未配置 |
| **生图（2D）** | `generate_image` → **fal** / **OpenRouter** | 概念图、贴图、UI 图标、天空盒 | fal / OpenRouter Key | ❌ 未配置 |
| **本地模型导入** | `import_model_file` | 把本机 FBX/OBJ/glTF/zip 导入并规范化 | 仅需文件 | ✅ 随时可用 |
| **程序化贴图** | `manage_texture` | 棋盘/条纹/渐变/噪声等纯代码生成贴图 | 无 | ✅ **无需任何 Key** |
| **编辑器内建模（关卡件）** | `manage_probuilder` | 用 ProBuilder 直接建/改关卡几何、道具 | 需装 `com.unity.probuilder` 包（**我可以装**） | ⚠️ 包未安装，可一键补 |
| **程序化音频** | 自写脚本生成 **WAV** | 合成音效（挥砍/命中/投掷/死亡）与简单循环 BGM | 无 | ✅ **无需任何 Key**（我能写 PCM WAV） |

### 3.1 需要你提供的东西（清单）

在 **Unity 编辑器 → MCP Tools 窗口 → Provider 密钥设置（secure store）** 中填入：

| 顺序 | Provider | 用途 | 备注 |
|---|---|---|---|
| 1️⃣ 推荐先配 | **Tripo** 或 **Meshy**（二选一即可） | 生成玩家/敌人/Boss 模型 | 有免费额度，注册即得 |
| 2️⃣ 强烈建议 | **Sketchfab** | 直接下现成模型（省时间，很多带动画） | 免费注册，部分模型免费 |
| 3️⃣ 可选 | **fal** 或 **OpenRouter** | 概念图、贴图、UI 图标 | 按量付费，很便宜 |
| 4️⃣ 完全可选 | Mixamo（Adobe 账号） | 免费人形动画库 | **不需要 Key 给我**，需要你自己在浏览器下载 FBX |

> 🔒 说明：这些 Key 存在 Unity 编辑器的**安全存储**里，**不会经过我**、也不会出现在我的上下文或文档中。我只负责调用工具。

### 3.2 对 AI 生成能力的诚实评估

**能做好**
- 静态模型本体（人形/怪物/道具）—— 质量已可用于课程设计
- 自动人形绑定（Tripo 的 rigging）—— 能省掉手动绑骨
- PBR 贴图、2D 概念图、UI 图标

**做不好 / 不要指望**
- ❌ **文生动画**（"生成一个挥剑动作"）—— 目前不可靠
- ❌ 精确控制骨骼与动作细节
- ❌ 多角色风格统一（每次生成风格会漂移 → 需要固定 prompt + 参考图）
- ❌ 低面数优化、uv 规整（生成的模型面数往往偏高，需 Blender 减面）

**关键做法**：**"模型可以生成，动作必须复用或借"**。

## 4. Blender 到底要不要？

### 4.1 结论

**V1 不必须。** 只有出现下面这些需求时才值得装：

| 场景 | 为什么需要 Blender | 我能做什么 |
|---|---|---|
| 批量把动画**重定向**到新角色并导出 FBX | Unity 内也能做，但批量/精确处理 Blender 更快 | 写 `bpy` 脚本批处理 |
| 生成模型**减面**（面数太高影响性能） | 需要 Decimate | 写脚本自动减面 |
| **格式转换 / 合并材质 / 重命名骨骼** | 批处理效率高 | 脚本化 |
| 自己**做动作**（K 关键帧） | 唯一能从零做动画的地方 | 可写脚本，但"从零编舞蹈"不现实 |

### 4.2 如果要装

- 版本：**Blender 4.x LTS**（如 4.2 LTS），官方安装包
- 安装后可被我**命令行驱动**：`blender --background --python script.py`（适合批处理，不需要界面操作）
- 本机现状：**未安装**（已检查 `which blender` 与 `C:\Program Files\Blender Foundation`，均无）

### 4.3 我的建议

**先不装。** 先走"AI 生成/Sketchfab 拿模型 + Humanoid 重定向复用现有动画"这条路；等真遇到"批量重定向"或"模型面数爆炸"的具体问题，再装 Blender 也不迟。

## 5. 推荐管线

### 5.1 角色（玩家 / 剑兵 / 弓兵 / Boss）

```
① 获取模型
   A. Tripo/Meshy 文生（prompt 固定风格关键词）或 图生（先 fal 生概念图再转 3D）
   B. Sketchfab 搜索现成模型（优先选"含动画"或"已绑定"的）
   C. 复用现有：Boxer / Gunner / Slime 预制体换皮
                 │
② 骨骼必须是 Humanoid
   · 在 FBX 的 Rig 页设为 Humanoid 并 Configure（或用 Tripo 自动绑定）
   · 目标：拿到 Avatar
                 │
③ 动作 = 复用现有动画（重定向）
   · 把新角色的 Avatar 指到 PlayAC/新 Controller 上
   · 现有 Idle/Run/Dash/combo_01_1-4/Hit/Death 直接套用
   · 缺失动作从 Mixamo 下载（同样 Humanoid，可混用）
                 │
④ 缺失动作清单（需补）
   · 玩家：特殊攻击（剑·插地、长枪·投掷/召回）—— ⚠️ **跳跃已取消，不需要 Jump/Fall/Land**
   · 剑兵：Idle/Run/Attack/Hit/Death —— ✅ **全部可从 TKD 库复用**（见 ART-ASSETS.md §3.1）
   · 弓兵：Aim、Shoot —— 🔴 库里没有，需 Mixamo 或手 K（其余可复用）
   · Boss：全部招式动作（工作量最大，见 §7；⚠️ 招式表未定，量未知）
```

> 📘 **要自己手 K 动画的话，见 [`ANIM-GUIDE.md`](ANIM-GUIDE.md)** —— 含本项目 4 条硬约束（Humanoid / 动画事件 / 根位移 / 时长对齐）、三阶段 K 帧流程、导出导入设置、常见坑速查。
> ⭐ 实测：TKD 库有 **35 个 Humanoid 动作**，其中 `combo_02` 系列与约 20 个 `kick_*` **基本零引用**，可白拿给剑兵用；**真正必须手 K 的只有弓兵 `Aim`/`Shoot` 两个**。

> ✅ **Boss 已定为人形**（见 `GDD.md` §7.1），因此 Boss **同样吃 Humanoid 重定向红利** —— 不存在"非人形骨骼没有动画可用"的问题。
> Boss 要做出"大体型"的做法是**模型放大 + 动作幅度调整**，而不是重做骨骼。
> ⚠️ 但要注意：Boss 的**专属招式**（瞬移冲刺、砸地等）现有动画库里大概率没有，仍需从 Mixamo 找近似动作或手 K（招式表已确定暂缓，动画量待定）。

### 5.5 音频（无需任何 Key）

**方案 A：程序化合成（我可直接做）**
- 用脚本生成 PCM **WAV** 文件写入 `Assets/_Game/Audio/`
- 可合成：挥砍（噪声爆发 + 高通）、命中（低频闷响）、长枪投掷（whoosh 扫频）、落地插地（短促撞击）、冲刺（whoosh 扫频）、死亡（下滑音）、体力耗尽（短促低音）、按钮（短点击）
- BGM：可合成简单循环（和弦 Pad + 鼓点），**能用但谈不上好听**
- 优点：零依赖、零成本、完全可控、体积极小
- 缺点：音色"电子/简陋"，不如真实音效库

**方案 B：免费音效库**
- Freesound / Pixabay / Mixamo 系的免费音效（注意各自授权条款）
- 需要你下载后放进 `Assets/_Game/Audio/`，我来接线

**建议（你的决策是"两种方式都会用到"，按此分工）**

- **方案 A（程序化合成）—— 先做，用来跑通系统**：搭 `AudioManager` + 音量设置 + 存档接线，并覆盖那些网上不好找的音效（体力耗尽、UI 点击、技能充能、瞄准提示等）。
- **方案 B（现成素材）—— 用来提升听感**：对**听觉要求高的关键音效**（挥砍、命中、Boss 吼叫）与 **BGM**，用免费素材或你下载的文件替换。
- **关键设计（让两者能混用）**：`AudioManager` 走"**音效 ID → AudioClip**"查表播放（配一张 `AudioLibrary` 表）。这样**换音源完全不碰代码** —— 先用 A 占位，再逐个用 B 替换，随时可换。

## 7. 风险与注意

| 风险 | 说明 | 缓解 |
|---|---|---|
| **动画比模型难得多** | 缺动作会导致"有模型不会动" | 严格走 Humanoid 重定向；Boss 动作提前确认方案 |
| **AI 生成风格不一致** | 多角色像来自不同游戏 | 固定 prompt 模板 + 统一参考图 + 统一色调 |
| 生成的模型**面数偏高** | 影响性能 | 需要时用 Blender 减面（这就是装 Blender 的理由） |
| **骨骼必须 Humanoid** | 非人形骨骼无法复用现有动画 | 拿到模型第一件事：设 Humanoid 并 Configure |
| Boss 若是**非人形** | 没有重定向可用 | 优先选含动画的市场资源，或改设计为"人形巨型敌人" |
| 授权与署名 | TKD 资源包 + Sketchfab/Mixamo/AI 生成物各有条款 | 课程设计要求提交源码时，**列出所有第三方资源与来源**（报告加分项） |
| AI 生成额度限制 | 免费额度可能不够反复试 | 先用概念图定稿，再生成 3D，减少返工 |
| 生成/下载的模型**材质管线** | 必须是 URP 兼容（否则变粉） | 导入后把 shader 转 URP/Lit；我可以批量处理 |
