## 给新会话（AI）的最短路径

1. 读 `PROJECT-CONTEXT.md` §1–§6 → 了解定位、环境、目录、类职责、运行链路
2. 读 `PROJECT-CONTEXT.md` §9 → 了解已知问题（改代码前必看）
3. 读 `ARPG-DIRECTION.md` → **关卡结构已变更，务必先看这个**（决策 + 架构约束）
4. 读 `ROADMAP.md` → 确认当前该做哪一步（**下一步：M2.2 开局二选一**）
5. 按需读 `GDD.md`（要做什么）、`ART-ASSETS.md`（缺什么）、`NAVMESH-GUIDE.md`（寻路怎么做）、`ANIM-GUIDE.md`（动画怎么做）
6. 文档与实际代码不一致时，**以代码为准**，并回来更新文档
7. ⚠️ **ROADMAP 里各阶段的"现状"描述可能停在写作时的状态**（已多次实测过期，
   例如 `WeaponConfig` 曾被写成"待改造"、实际已被删除）——**动手前先实查代码**
