## 给新会话（AI）的最短路径

1. 读 `PROJECT-CONTEXT.md` §1–§6 → 了解定位、环境、目录、类职责、运行链路
2. 读 `PROJECT-CONTEXT.md` §9 → 了解已知问题（改代码前必看）
3. 读 `ROADMAP.md` → 确认当前该做哪一步
4. 按需读 `GDD.md`（要做什么）、`ART-ASSETS.md`（缺什么）、`NAVMESH-GUIDE.md`（寻路怎么做）
5. 文档与实际代码不一致时，**以代码为准**，并回来更新文档
