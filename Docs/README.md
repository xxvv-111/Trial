## 一句话现状

Unity 6 的 **3D 动作 RPG（ARPG）** —— **第三人称斜俯视**。当前已具备完整**动作层**：开始界面 / 清怪 / 结束界面 / 玩家战斗 / 基础敌人 / 打击特效。
⚠️ **RPG 层（跳跃 / 掉落 / 成长 / 数值养成）尚未实现** —— 2026-10-09 定为规划方向。

**进度**：阶段 0 ✅（脚本 50→37，修 4 个真 bug）· **M1 系统骨架全部 ✅**（魔力 / Hitbox / 暂停菜单 / 文案）· **M2 武器（剑）全部 ✅**（武器配置 / 装配剑 / 4 段连段动画 / **火球特殊攻击**）· **M3.1 NavMesh 烘焙 ✅ + M3.2 敌人状态机基类 ✅ + M3.3 视野感知 ✅ + M3.4 剑兵 Alert/Reposition ✅ + M3.5 法师（远程）✅**（651 三角形导航网 + 6 个障碍物 + **敌人状态机自测 39 项全通过**；🔄 弓兵已改定为**法师**，两敌统一 5 个动画状态）· 玩家模型换为 **Roskva**（Humanoid，Neck 已修）· 相机改为鼠标控视角 ✅（可仰视）· 🔄 资源改回**魔力**：移动/冲刺/普攻免费、**只有特殊攻击消耗**、**且不再自动回复** · 🐞 冲刺穿墙已修（T27：位移改走 `CharacterController`）· 🎮 攻击中"不移动但可限速转向"（方案 B 转向窗口）

## 给新会话（AI）的最短路径

1. 读 `PROJECT-CONTEXT.md` §1–§6 → 了解定位、环境、目录、类职责、运行链路
2. 读 `PROJECT-CONTEXT.md` §9 → 了解已知问题（改代码前必看）
3. 读 `GDD.md` §9 → **场景结构（单一大型主场景，10-07 定稿）**；需要**相机**细节或**方案选型素材**时读 `ARPG-DIRECTION.md`（⚠️ 其 §4.6 仍然生效）
4. 读 `ROADMAP.md` → 确认当前该做哪一步（⚠️ M1~M4 主体已完成，**下一步：任务系统**，它依赖已落地的存档层；额外项目见 §13）
5. 按需读 `GDD.md`（要做什么）、`ART-ASSETS.md`（缺什么）、`NAVMESH-GUIDE.md`（寻路怎么做）、`ANIM-GUIDE.md`（动画怎么做）
6. 文档与实际代码不一致时，**以代码为准**，并回来更新文档
7. ⚠️ **ROADMAP 里各阶段的"现状"描述可能停在写作时的状态**（已多次实测过期，
   例如 `WeaponConfig` 曾被写成"待改造"、实际已被删除）——**动手前先实查代码**
