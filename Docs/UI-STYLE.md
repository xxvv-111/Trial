# UI 风格规范（v4 · 电影感）

> 定稿：2026-10-20　｜　样板：`MainMenu` v4　｜　依据：用户实拍截图 `屏幕截图 2026-10-07 150200.png`
> 后续所有界面（HUD / 酒馆面板 / 结算）默认沿用本文，除非明确要求换风格。

---

## 0. 一句话

**写实画面为底，UI 只做排版**：不加面板、不加边框、不加材质，靠一层遮罩和 1~2px 的细线建立秩序。
参考气质：《Elden Ring》《Dark Souls III》《Bloodborne》的主菜单。

---

## 1. 前提（什么时候适用）

1. 背景是实拍截图或渲染画面（有真实光照、景深、噪点）——这是整套风格成立的前提。
2. 背景不是纯色或插画。纯色背景请走 `Docs/UI-PLAN.md` 里的面板式方案。
3. UI 元素只承担信息，装饰一律退化为线。

---

## 2. 配色（全部从截图像素取样，不凭空定）

1. 主文字：暖白 `#EDE8DE`（`237,232,222`）
2. 次文字 / 副标：冷灰 `#B6AC9A`（`182,172,154`）
3. 分割线 / 按钮下线：`rgba(140,133,120,0.45)`，hover 提亮到 `rgba(240,230,210,0.95)`
4. 强调：暖白提亮 `#FFF6E4`
5. 禁用：文字 `#6B6B66`、线 `#474745`（低对比，但保留形状）
6. 遮罩：纯黑，按区域给 alpha（见 §5.1）
7. ⚠️ **禁用金色**。背景里的暖色是**火光橙**（`#C87A3C` 一类），不是金；金色一上就变手游。

---

## 3. 字体

1. **英文标题：Cinzel Regular**（OFL 授权，不加粗），字距约 `0.25em`
   - 加粗（700）会立刻廉价，这是 v3 翻车的直接原因之一
2. **中文副标：仿宋**（STFangSong），字距约 `0.5em`，小字号、低对比
3. **TMP 正文/按钮：`sarasa-gothic-sc-regular SDF`**（工程内已有），字距 6~8
4. 字号（参考分辨率 1920×1080）：
   - 位图标题：132px（成品显示 660px 宽）
   - 按钮文字：26px
   - 操作提示：16px
   - 版本/版权：16px
5. ⚠️ 英文标题做成**位图**（不做 TMP）：需要衬线 + 细线 + 投影，TMP 做不到。
6. ⚠️ TMP 文字**直接指定中文字体资产**，不要依赖 `LiberationSans` 的 fallback 链（见 §7.3）。

---

## 4. 布局

1. 参考分辨率 **1920×1080**，`CanvasScaler = ScaleWithScreenSize`，`Match = 0.5`
2. 安全边距 **44px**（版本号、版权贴边）
3. 标题中心 `(0, 340)`，尺寸 `660×366`（位图 582×323，等比放大）
4. 主按钮组 `y = -390`，三个横排：`x = -260 / 0 / +260`，尺寸 `240×56`
5. 操作提示 `(0, -462)`，水平居中，宽 1500
6. 版本号右下 `(-44, 30)`、版权左下 `(44, 30)`

---

## 5. 组件规范

### 5.1 遮罩（scrim）—— 整套风格的命门

没有它，写实背景上的白字一定看不清。`ui_bg_scrim.png` 由四层叠加：

1. 竖向基础遮罩：全屏 `alpha 40`；顶部 380px 从 `alpha 114` 渐变到 0；底部 380px 从 0 渐变到 `alpha 146`
2. 标题后方**径向暗化**：中心 `(960,170)`，半径 `700×210`，峰值 `alpha 62`，模糊 90 —— 用椭圆不用矩形，看不出边界
3. 按钮后方径向暗化：中心 `(960,938)`，半径 `720×128`，峰值 `alpha 118`
4. 暗角：椭圆外圈 `alpha 140`，模糊 `W×0.08`

### 5.2 标题

1. 结构：`TRIAL`（Cinzel 132px 暖白）+ 上下各一条 1px 细线（宽 336，两端小菱形）+ `试 炼`（仿宋 34px 冷灰）
2. 必须有**柔和投影**（模糊 9、偏移 4px、`alpha 158`），否则压在亮部雪山上会糊成一片
3. 不加底板、不加边框、不加发光

### 5.3 按钮

1. 结构：透明 `Image`（吃射线）+ TMP 文字 + 底部 **2px 细线**
2. `Button.targetGraphic` 指向**细线**，`transition = ColorTint`
   - `normal = white`、`highlighted = (1.8,1.7,1.55)`、`pressed = (0.72,0.7,0.66)`、`disabled = (0.45,…)`
   - hover 时只有线变亮，文字不变 —— 克制，但足够
3. 尺寸 `240×56`，文字 26px、字距 8、居中
4. 禁用态：文字 `#6B6B66`、线 `#474745`、`interactable = false`、`raycastTarget = false`

### 5.4 次级信息

1. 操作提示、版本号、版权：16px，冷灰 `alpha 170~190`，不加背景
2. 不用分隔线（v3 的 Divider 已删除）

---

## 6. 禁止清单（踩过的坑）

1. 木板 / 皮革 / 金属**材质贴图**（v2 的木板按钮 = 手游感）
2. 铭牌底、双层边框、四角角饰（v3 的做法；除非整套 UI 都是这个语言）
3. 粗描边（> 2px）和发光描边
4. 高饱和金、渐变金
5. 圆角按钮
6. 图标 + 文字混排的按钮（没有真实图标时更难看）
7. 彩色面板（半透明有色底会污染背景色调）

---

## 7. 技术实现

1. **图层顺序**：`BG_Backdrop`（截图，`preserveAspect = false`）→ `BG_Scrim` → 标题 → 按钮 → 页脚
2. 背景图轻微拉伸优于留黑边：原图 2095×1234（1.697）拉到 1920×1080（1.778），横向 4.5%，看不出来
3. **中文字体**：
   - 直接 `lbl.font = AssetDatabase.LoadAssetAtPath<TMP_FontAsset>("Assets/1_Asset/4_Font/sarasa-gothic-sc-regular SDF.asset")`
   - ⚠️ 该资产是 Dynamic 模式，**图集 1024 曾是瓶颈**（占 88.6% 后新字生成失败 → 显示 □）
   - 出现 □ 时跑 `Tools/UI/修复中文字体（TMP Fallback）`（扩到 2048 + 开多图集 + 清空动态字形）
4. 贴图导入：`Sprite (Single)`、`Alpha Is Transparency`、关 mipmap、`Max Size 4096`、`CompressedHQ`
5. 相机 `Clear Flags = SolidColor`、背景近黑 `#030405`（防背景图边缘露色）

---

## 8. 交付检查清单

1. 在 1280×720 / 1920×1080 / 2560×1440 三档下，文字都清晰、不溢出
2. 截图里最亮的一块（本例是城堡火光）上没有压文字
3. hover / pressed / disabled 三态都能看出来
4. 中文没有 □；英文没有断词
5. 遮罩边缘看不出矩形痕迹（必须是径向/渐变）
6. 关掉背景图单看 UI，会觉得“太空”——这是对的，说明没有多余装饰
